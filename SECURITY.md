# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to the maintainer (address in the Git commit history), not in a public issue.

Provide:
- Affected component
- Reproduction steps
- Impact assessment
- Suggested remediation (if available)

## Response targets

- Initial acknowledgement: 3 business days
- Triage result: 7 business days
- Coordinated disclosure target: 30 to 90 days
